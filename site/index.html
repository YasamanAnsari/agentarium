DATA DICTIONARY

One agents table. Every claim quoted.

agents.csv

One row per agent. A permanent agent_id, display name, description, homepage, source URL, first-seen date, repository creation date, GitHub stars, main task, license, and marketplace pricing model.

tasks.csv · agent_tasks.csv

A shared vocabulary of eight tasks, and one row per agent–task claim with a source URL and a verbatim evidence quote.

agent_activities.csv

One row per agent and O*NET 29.2 Detailed Work Activity (dwa_id), with a verbatim quote. O*NET's own crosswalk links each activity to occupations' tasks.

attributes.csv · agent_attributes.csv

How each agent works: autonomy level, tool classes, and audience, each with a verbatim quote.

agent_packages.csv · agent_results.csv

Registry packages that name the agent's repository with last-month downloads, from ecosyste.ms; and SWE-bench submissions whose listed site is the agent's address.

Download the tables: agents · agent_tasks · agent_activities · agent_attributes · agent_packages · agent_results · occupation_coverage. A documented claim records what a project says it does. It is not a measured capability.
