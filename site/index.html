0000/Overview

DATA DICTIONARY

Three tables. Clear connections.

agents.csv

One row per agent. A permanent agent_id, display name, description, homepage, source URL, and first-seen date.

tasks.csv

A shared task vocabulary. Each task_id has a name and definition, so equivalent tasks use the same label.

agent_tasks.csv

One agent–task connection, identified by agent_id + task_id, with a source URL and a verbatim evidence quote.

Download the full tables: agents.csv · tasks.csv · agent_tasks.csv. A documented claim records what a project says it does. It is not a measured capability.
